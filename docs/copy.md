# 일본어 문구 규칙

사용자는 서울을 찾는 일본인 관광객입니다. 화면 문구는 모두 일본어로 쓰고, `src/shared/i18n/ja.ts` 한 곳에만 둡니다. 날짜·시간·가격·개수 표시는 `src/shared/i18n/format.ts`의 함수를 씁니다.

## 1. `ja.ts` 구조

| 섹션                                                | 넣는 것                                                            |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| `common`                                            | 두 화면 이상이 쓰는 말 (로딩, 에러, 다시 시도, 無料, 原文を見る …) |
| `format`                                            | 날짜·가격·개수의 조각. 화면에서 직접 쓰지 않고 `format.ts`가 씀    |
| `screens`                                           | 화면 이름 (S01~S18)                                                |
| `nav`, `topBar`                                     | 하단 탭 바, 상단 바                                                |
| 화면·기능별 (`login`, `eventDetail`, `companion` …) | 그 화면에서만 쓰는 문구. 섹션 이름은 camelCase 기능 이름           |

- 다른 화면의 섹션은 고치지 않습니다. 같은 말을 여러 화면이 쓰게 되면 `common`에 더하고, 각 화면이 자기 PR에서 옮깁니다.
- 숫자·이름이 들어가는 문구는 함수로 만듭니다: `` companionCount: (count: number) => `${count}件` ``. 컴포넌트에서 문구 조각을 `+`나 템플릿으로 이어 붙이지 않습니다 (일본어는 어순이 달라 조각을 이으면 어색해짐).
- 에러 code별 문구는 화면 섹션 안에 `errors: { CODE: '…' }`로 둡니다 (예: `companionDetail.errors.POST_FULL`). 서버 `message`는 화면에 보여 주지 않습니다.
- `aria-label`, `alt`, 제목(`<title>`)도 화면 문구라서 `ja.ts`에서 가져옵니다.

## 2. 말투

- 정중체(です・ます)로 짧게 씁니다. 존경어·겸양어를 겹쳐 쓰지 않습니다 (`ご確認ください`까지는 괜찮고 `ご確認いただけますでしょうか`는 길다).
- 버튼은 동사로 끝냅니다: `募集する`, `一緒に行く`, `もう一度試す`. `〜してください`를 버튼에 쓰지 않습니다.
- 안내·에러는 무엇이 일어났는지 + 할 수 있는 일을 한 문장씩: `通信できませんでした。電波の良い場所でもう一度お試しください。`
- 사용자 탓을 하는 말(`不正な入力です`)보다 고치는 방법을 씁니다: `60文字以内で入力してください`.
- `！`는 성공·축하 순간에만 씁니다 (예: `マッチング成立！`). 에러·경고에는 쓰지 않습니다.

## 3. 표기

| 대상      | 규칙                                                | 예                              | 함수                          |
| --------- | --------------------------------------------------- | ------------------------------- | ----------------------------- |
| 날짜      | `M月D日（曜）`, 괄호는 전각                         | `11月29日（土）`                | `formatDay`                   |
| 기간      | `〜`로 잇고 띄어 쓰지 않음. 해가 바뀌면 양쪽에 연도 | `11月1日（土）〜11月30日（日）` | `formatDayRange`              |
| 시간      | 24시간, 2자리                                       | `18:00`                         | `formatTime`                  |
| 날짜+시간 | 날짜 바로 뒤에 시간                                 | `11月29日（土）18:00`           | `formatDateTime`              |
| 가격      | 0이면 `無料`, 그 밖은 쉼표 + `ウォン`               | `無料`, `5,000ウォン`           | `formatPrice`                 |
| 개수      | 숫자는 반각, 쉼표                                   | `3件`, `2人`                    | `formatCount`, `formatPeople` |

- 날짜·시간은 언제나 서울 시간(`Asia/Seoul`)으로 보여 줍니다. 일본과 시차가 없어서 따로 표시하지 않습니다.
- 숫자·영문은 반각, 괄호·물음표·느낌표는 전각(`（）`, `？`, `！`)입니다.
- 로딩 중 문구는 `…`(말줄임 한 글자)로 끝냅니다: `読み込み中…`, `投稿中…`.
- 문장에는 `。`를 붙이고, 제목·버튼·라벨·태그에는 붙이지 않습니다.
- 행사는 `イベント`로 씁니다 (`行事`는 학교·의식 느낌이라 쓰지 않음). 같은 대상에는 화면이 달라도 같은 말을 씁니다.

### 용어

| 뜻        | 쓰는 말      | 쓰지 않는 말                 |
| --------- | ------------ | ---------------------------- |
| 행사      | イベント     | 行事, 催し                   |
| 도착 인증 | 到着チェック | チェックイン                 |
| 다시 시도 | もう一度試す | 再読み込み, リトライ         |
| 원문 보기 | 原文を見る   | 韓国語で見る                 |
| 번역 없음 | 日本語訳なし | 翻訳なし                     |
| 무료      | 無料         | タダ, FREE(장식 글자는 예외) |

## 4. 한국어 원문

- 화면에 한국어를 쓰는 것은 API가 준 원문(행사명·장소·주소 등)을 보여 줄 때뿐입니다. `ja.ts`에 한국어 UI 문구를 넣지 않습니다.
  - 예외: 원문을 보여 주는 장식용 예시(S01 히어로의 `sampleOriginal`)는 `ja.ts`에 둘 수 있고, 표시할 때 `lang="ko"`를 붙입니다.
- 원문을 그리는 요소에는 `lang="ko"`를 붙입니다. 화면 낭독기와 글꼴 선택이 한국어로 바뀝니다.
  - `<span lang="ko">{event.title}</span>`
  - 일본어(`titleJa`)가 없어 원문을 대신 보여 줄 때도 `lang="ko"`. 일본어가 있을 때는 붙이지 않습니다.
- `…Ja`가 null이면 원문 옆에 `ja.common.noTranslation`(`日本語訳なし`)을 작게 붙입니다. 기계 번역이면 `ja.common.autoTranslated`(`自動翻訳`)를 붙입니다.

## 5. PR 전 체크리스트

- [ ] 새 문구가 모두 `ja.ts`에 있고, 컴포넌트에 일본어·한국어 문자열이 직접 없다 (`git diff`에서 `src/features`, `src/pages`의 따옴표 안 일본어 확인)
- [ ] 숫자·이름이 들어가는 문구는 함수이고, 조각을 이어 붙이지 않았다
- [ ] 날짜·시간·가격·개수는 `format.ts` 함수를 썼다
- [ ] 버튼은 동사, 문장은 `。`, 제목·라벨에는 `。` 없음
- [ ] 용어표의 말을 썼다 (`イベント`, `もう一度試す` …)
- [ ] 원문 한국어 요소에 `lang="ko"`가 있다
- [ ] `aria-label`·`alt`도 일본어다
- [ ] 390px에서 긴 문구가 넘치지 않는다 (가장 긴 행사명·에러 문구로 확인)
